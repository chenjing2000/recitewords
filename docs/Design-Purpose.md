# 设计目的与范围

ReciteWords 是 Windows 上的本地单词背诵软件，使用 C#、WPF 和简单 MVVM。目的在于让用户用已有 JSON 单词本和本地英美音频完成查看、评价、复习，并在下次打开时保留各词的学习状态。

## 核心使用方式

- 选择文件夹与单词本，按全部、未学、不懂、认识、掌握筛选；下拉项显示各类数量。
- 单词出现时隐藏释义，并自动播放存在的英音。可以直接评价，也可以先显示释义。
- 评价保存后进入下一词；前后导航不评价。后退重新评价立即覆盖原状态，不累计评价次数。
- 用户自己决定何时复习。每轮使用固定词序，评价改变分类数量，但不动态移除本轮队列中的词。
- 本地音频缺失时禁用对应按钮；不联网下载、不使用语音合成、不以美音替代缺失的英音。

状态采用“不懂 / Unknown、认识 / Familiar、掌握 / Mastered”；没有评价记录的词归入未学。

## 数据与交付

单词本、音频索引、学习进度、应用设置分别保存，不增加数据库。每本单词本使用自身目录的 `userdata/<单词本文件名去掉扩展名>.progress.json`，缺少时初始化；记录按标准化后的 `word` 关联，只保存当前状态。词库改名后查找或新建对应记录，由用户维护旧文件，不自动迁移。损坏进度报错，不提供自动恢复或重置入口。

应用设置保存在程序旁的 `recitewords.settings.json`，保存上次文件夹、单词本和窗口信息。发布采用依赖已安装 .NET 10 Windows Desktop Runtime 的目录方式，与 EnglishBench 相同；没有安装包、单文件包或 Python 运行依赖。具体操作见 [运行与交付](Getting-Started.md)。

## 界面目的

提供可缩放的紧凑窗口，保持词汇、读音、释义和评价的操作顺序清楚。窗口最大宽度为所在屏幕宽度的 70%，最大高度为工作区高度；最小尺寸由控件与至少四行释义内容决定。释义自动换行、允许手动滚动，不自动滚动。

正常操作不显示提示；警告和错误在底部展开，5 秒后清空并折叠。音频按钮直接点击喇叭播放。界面具体尺寸、颜色和缩进见运行文档，避免在多个文档中重复维护。

## 实现原则

按文件读写、复习逻辑、音频、界面分工，通过少量明确接口交互。采用普通类、直接控制流程和手工组装，不使用依赖注入容器、通用插件框架或复杂继承体系。允许少量局部重复，优先保证代码直观、模块职责集中。

本项目不负责生成语音、管理在线账户、云同步、编辑词库或自动安排复习日程。单词格式 skill 只负责指导生成与检查单词本内容。

## 当前格式与读取方式

单词规则见 [格式 skill](skills/recitewords-wordlist-format/SKILL.md)：删除 wid，必填 word、phonetic_uk、phonetic_us 和非空 senses，每个词义必填 pos、chinese_meaning。界面顺序为英音音标、英音喇叭、美音音标、美音喇叭。

音频文件名主体 stem 将 word 去除首尾空白后逐个替换非 ASCII 字母/数字为 `_`，不合并下划线、不转换大小写。导入拒绝转换后文件名冲突，word 显示及进度键不变。

单词音频直接读取同名单词本子目录 audio/ 下的 `{stem}_uk.mp3/.wav`、`{stem}_us.mp3/.wav`，不再读取 audio.json。例句继续使用 eid 和 examples.json。

[版本 2 进度](Progress-Format.md) 只保存单词当前状态，不保存 review_count、position 或本轮会话。每次打开从全部分类第一词开始，运行时仍保留内存队列和位置，支持前后切词与重评。

此次为破坏性升级；旧词库与旧进度不兼容，不自动迁移或覆盖。未知词库字段仍忽略，但不能替代新格式的必填字段。
