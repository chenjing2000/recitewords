# 运行与交付

## 环境与启动

使用 Windows 和 .NET 10 Windows Desktop Runtime；本机验证版本为 10.0.11，SDK 为 10.0.400。无第三方 NuGet 包、数据库或 Python 运行依赖。

启动 `artifacts/app/ReciteWords.exe`，点击右上文件夹图标选择单词本目录。只扫描当前目录直属 JSON，不递归；无效文件跳过并提示，其它有效词库正常打开。上次目录、词库、窗口位置及尺寸存入 EXE 同目录的 `recitewords.settings.json`。程序和词库目录须可写。

## 进度与复习

每个单词本的进度位于其目录下 `userdata/<词库文件名去掉扩展名>.progress.json`；缺少时自动初始化，每次打开读取对应记录。记录通过标准化后的 word 关联单词，只保存当前状态。词库改名后读取或新建新名称记录，由用户自行维护旧文件。不读取或覆盖 Python 的旧进度。

状态为“不懂 / Unknown、认识 / Familiar、掌握 / Mastered”，未评价归入“未学”。底部筛选项显示当前单词本各状态数量，评价和重评成功保存后刷新。

切换筛选立即从该分类第一词开始本轮复习；每次打开词库从全部分类第一词开始，不恢复分类和位置。本轮采用固定队列，评价不会使队列跳词。箭头可前后导航；可后退重评，覆盖原状态。换词隐藏释义，可以不显示释义直接评价。完成后可后退，重新建立队列可切换分类。

评价立即保存；导航与筛选只改变内存会话，不写进度。保存失败回滚至原状态与原词；损坏记录只报错并禁止提交，用户自行检查，没有自动恢复或重置入口。

单词格式与 [格式 skill](skills/recitewords-wordlist-format/SKILL.md) 一致：无 wid，双音标必填，每个词义的 pos 与 chinese_meaning 必填。只接收 [版本 2 进度](Progress-Format.md)，不兼容旧文件，不自动迁移或覆盖。

## 音频

`education.json` 的单词音频放在同目录 `education/audio/` 下，直接按 `{stem}_uk.mp3`、`{stem}_us.mp3` 查找，也支持同名 WAV，MP3 优先。不读取旧 `audio.json`。主体 stem 由 word 去除首尾空白后，将每个非 ASCII 字母/数字替换为 `_` 得到；不合并或去除下划线、不转换大小写。例如 one's own 使用 one_s_own_uk.mp3。导入时拒绝主体不区分大小写的冲突，并列出冲突词条；word 显示及进度键不变。已有音频不会被自动重命名，也不按旧文件名回退。例句保留 `education/examples.json` 版本 1，按 eid 精确匹配，索引相对路径以 `education/` 为基准。没有 eid 时例句仍显示，但不能关联音频。

出现单词时自动读 UK；US 手动点击。缺失音频禁用对应喇叭，不下载、不合成。单词和例句共用播放器，新播放停止旧播放，快速切词会取消尚未执行的旧播放。

喇叭使用 EnglishBench 右侧词汇区的 🔊 字符（Segoe UI、11pt），无背景和边框，直接点击播放；单词行依次显示英音音标、英音喇叭、美音音标、美音喇叭，整组居中；悬停可查看说明。英文例句的两个喇叭在句末，与末尾单词一起换行，不单独另起一行；中文译文在后续一行。

## 界面

窗口最大外宽为当前屏幕宽度的 70%，最大高度为工作区高度；最大化也遵守此限制。窗口下限按控件宽度、固定行和至少四行释义文字计算，不能缩到遮盖控件。混合 DPI 多显示器行为须在相应设备上验收。

界面默认 11pt，单词 12pt、#b81a35。pos、english_meaning、chinese_meaning 内容为 #c8161d，register 保留原色；其它字段标题为 #007175，正文保留原色。字段/词性首行左对齐，其它行缩进 2em。正文行高 20 DIP，自动换行；滚动条宽 7 DIP，只由用户手动滚动。

底部依次为筛选、上一词、下一词、释义、不懂、认识、掌握。筛选基础宽度 95 DIP，较长数量按所需文字宽度加宽；筛选与图标按钮宽度不随窗口缩放。普通按钮高度 32 DIP，喇叭点击区域为 20 DIP。已删除起始序号、复习按钮及底部位置标签。

提示栏仅在警告/错误时展开，5 秒后清空并折叠，新提示重新计时。折叠后评价按钮下移、释义区变高。过长提示可悬停查看全文，正常操作不提示。

窗口与 EXE 使用 ui/mainicon 图标；文件夹、前后词及释义使用对应 SVG 转成的矢量资源。源素材位于 `ReciteWords/ui`，更换后使用带 Pillow 的 Python 执行 `tools/build_ui_icons.py` 并重新构建；程序运行不需要此工具。

## 构建、测试与发布

命令见 README。测试在 `artifacts/tests` 创建独立临时目录并自行清理；`--ui-qa` 生成当前验收截图。WAV/MP3 解码检查静音执行，不能代替真实发音试听。

关闭应用，发布到暂存目录并验证，再将 ReciteWords.exe、ReciteWords.dll、ReciteWords.deps.json、ReciteWords.runtimeconfig.json 四个文件复制到 `artifacts/app`。保留设置、wordlist 和 userdata。清理后 bin/obj 已删除，下次正常构建会自动恢复依赖元数据并生成编译文件。

.gitignore 排除发布产物、编译文件和个人数据；上传 GitHub 时提交源代码、文档、开发工具与固定测试夹具即可。
